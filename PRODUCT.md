# Threadwork

## Register

product

## Platform

macos

## Users

A Mac user moving between their own, parents’, in-laws’, and other networks.

## Product Purpose

See this Mac’s network usage, discover visible devices, run quick connection diagnostics, and remember familiar networks locally.

## Positioning

A quick-access utility like LocalPulse, with dot-matrix usage charts rather than a network-node map or desktop dashboard.

## Design Principles

Show measured traffic. Distinguish this Mac’s usage from unavailable traffic on other devices. Familiarity improves history, not network access. Keep the first version compact and directly useful.
